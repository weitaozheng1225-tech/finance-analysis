## 核心论点（执行摘要）

1. **三国长端同步上行的本质不是周期问题，而是"主权信用 + 期限溢价 + 边际买家"的结构性重定价**。任何单一指标都不足以判断危机，必须看"利率水平 × 波动率 × 流动性 × 融资压力"的联立。

2. **最高概率的危机形态不是美债违约**，而是 *流动性事件*（类似 2019/9 回购、2020/3 美债"dash for cash"、2022/9 英国 LDI）。央行通常会在数日到数周内介入。

3. **美债技术性违约（debt ceiling X-date 失误）概率显著高于实质性违约**，前者会迅速被政治压力解决但会留下永久性期限溢价；后者意味着美元体系重构，概率 < 1% 但尾部成本极大。

4. **最先发出系统性信号的不是收益率本身，而是 MOVE 指数、SOFR-IORB 利差、跨境基差互换、美债拍卖尾差与一级交易商持仓**。收益率突破新高是"果"，上述指标是"因"。

5. **日本因素是被低估的全球流动性变量**。日本寿险与银行是全球高评级债券的边际买家，JGB 30Y/40Y 收益率每上行 25bp，理论上对应数千亿美元级别的潜在回流压力。
